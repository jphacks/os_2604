# 15秒健康チェック — os_2604

毎朝、顔位置確認後に15秒間撮影し、記録と過去の自分との差を振り返るFlutter製の検証用MVP。診断を目的としません。

C担当の計測API・iOSカメラ接続・品質判定・ScanWidgetは [C担当の接続メモ](docs/c-integration.md) を参照してください。

デモ手順・受け入れ試験表は [デモ手順](docs/demo-guide.md) を参照してください。

iPhone用の外部LED通知を追加しました。設定でキットを検索・選択し、LEDテストで実物を確認してから計測保存との連動を有効にします。Bluetoothプラグイン・利用説明の反映にはiOSの再ビルドが必要です。iPhone 17／iOS 27.0.1とE84で、単体疎通・計測後の点灯／消灯・中断時の誤点灯防止・再接続・オフライン2回をユーザー確認済みです。強制的な保存失敗・通信タイムアウト・AI失敗の実機再現は未実施です。[LEDデモ・試験手順](docs/e84-led-demo.md) と [キットのファームウェア手順](firmware/e84/README.md) を参照してください。

室温・湿度の任意取得を追加しました。設定の「環境情報を取得する」をオンにし、環境対応ファームウェアへ接続すると「キット付近」の現在値を表示します。有効計測終了時の1サンプルを健康記録とは別に保存し、結果・履歴から再表示できます。体温・AIレポートには混ぜません。既存LEDファームウェアは環境未対応としてLEDを維持します。環境対応版を実機へ更新し、既存記録を保持したv7移行を確認しました。ライブ温湿度・保存と履歴・LED連動・オフライン2回の主要動線はユーザー確認済みです。センサー精度や強制障害試験は未確認です。[環境デモ・試験状況](docs/e84-environment-demo.md) を参照してください。

## 通常／研究モード

撮影画面で開始前に「研究モード」をオンにすると、心拍・顔色の試験的推定を行います。画面を開くたび通常モードへ戻ります。通常では実験処理を行わず値は未測定。開始後・再試行中・保存中は切替不可です。各記録にモードを保存し、結果・履歴詳細・レポートに表示します。

心拍の実機比較は1回で精度保証ではありません。品質不足時は数値を出さず、診断や健康判断には使用しません。[制約・最終確認票](docs/c-validation.md)、[B・C接続状況](docs/c-integration-status.md)を参照してください。LED版は本ブランチへ未統合です。

## 環境

Flutter **3.47.7 stable / Dart 3.13.5**。推奨版は `.flutter-version` に記録。

正式対象は **iPhone 17 / iOS 27以降**。

```sh
flutter pub get
dart run build_runner build
flutter devices
```

## 通常／研究モード

設定の「研究モード」で次回撮影のモードを選びます。初期値はオフ（通常）で端末内に保存します。撮影画面は選択済みモードで自動開始します。オンの場合のみ心拍推定・顔色特徴量の実験処理を行い、品質不足なら数値は出しません。診断・健康判断には使用できません。DB schema v6は設定テーブルの追加のみで既存記録を保持します。
