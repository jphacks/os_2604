## 2026-10-17 cブランチの互換性修正

- ユーザー回答：現在の開発フェーズはDay 1。
- ユーザー承認：旧DBの日時は「2026年の秒値だけ変換する」。UTCの2026-01-01以上・2027-01-01未満に相当するUnix秒値を100万倍し、マイクロ秒へ統一する。その他の値は保持する。新しい入力日時を2026年に制限する仕様ではない。
- 旧v2と通知追加後のv3には秒・マイクロ秒の単位情報がない。現行のマイクロ秒値を一律に変換せず、schema v4への移行で上記範囲だけを更新する。範囲外の旧秒値や、同じ整数値になる1970年付近のマイクロ秒値の完全判別はできない。別の期間への対応は追加判断が必要。
- 移行はテーブル追加と日時更新を同じトランザクションに含める。失敗は呼び出し側へ返し、既存記録を削除・初期化して回復しない。記録のID・任意入力・NULL・本文・生成モード・説明確認・既存通知設定を保持する。
- カメラ権限確認は計測前に行う。共有進捗へ`requestingPermission`を追加し、利用側の撮影画面も同時に更新する。この状態での一時的な`inactive`だけは待機し、背景化・画面離脱は引き続き中断する。カメラ初期化は許可と前面復帰の後に行い、実計測の15秒と初期化の10秒制限にOSダイアログの待ち時間を含めない。
