PROJECT  /  15-SECOND MORNING CHECK
3人・2日間  分業／進行計画書
版数 0.1  ｜  2026年10月17日  ｜  3名・2日間のプロトタイプ開発向け
成功条件（16時間想定の2日間）
・「ホーム → 顔の位置確認 → 15秒撮影 → 結果／自己申告 → ローカル保存 → 履歴」という一連の操作が実機で動く。
・オンデバイスAIは対応実機1台での動作を目指す。利用不可なら定型レポートでも途切れない。
・心拍数推定は研究課題として分離。精度未検証の数値は健康状態の判定に使わない。

05  GitHubでの共同作業ルール
•  mainは常時ビルド可能にする。作業はfeature/ui、feature/app、feature/vision-aiなどからプルリクエストで取り込む。
•  共通ファイル（pubspec.yaml、ios/・android/の権限、main.dart）はBが変更窓口。Cが変更する場合は先に共有。
•  Bはモック実装を先に用意し、Cの処理が完成していなくても全画面を動かせるようにする。
•  各タスクの完了時に実機で動作確認。最低でもD1昼、D1終了、D2昼、D2終了に統合する。
•  計測失敗・AI失敗の表示は「動くこと」と同じ重みでレビューする。
想定フォルダの所有権
lib/screens/・lib/widgets/        → B（Aがレビュー） lib/models/                       → B / C 共同契約 lib/services/db/・notifications/  → B lib/features/scan/                → C lib/services/ai/                  → C ios/・android/                    → B管理、Cと相談して変更 design/（Figmaリンク・素材）     → A
