## ブランチ

- UI統合用：`codex/ui`。main `247f552` から作成。
- 各画面はこの親ブランチから作業ブランチを切り、PRの取り込み先を `codex/ui` にする。人間がマージする。
- 最初の反映：`codex/ui-history`。履歴一覧・今日の記録・週間の花・記録なし。
- 次の単位：オンボーディング、計測表示、結果／入力、設定、推移グラフ。親へ取り込まれた共通部品を次のブランチで利用する。
- 全画面反映（2026-10-18）：`add/20261018-apply-asakao-design-to-all-screens`（`codex/ui-history` 0f650cb から作成）。PR取り込み先は `codex/ui`、マージは人間。Liquid Glassタブバー（`camera_tab_bar.dart`／`CameraTabBar.swift`／`main_tabs_screen.dart`）以外の残り全画面にアサカオデザインを適用。タブバー3ファイルは基点から差分なし。
  - d945328 共通UIキット（`lib/ui/asakao_style.dart`、`asakao_widgets.dart`、`asakaoTheme`）
  - 80f80ba 初回設定1-1〜1-7・設定6-1／6-3／6-3'・このアプリについて6-4・通知設定サブページ
  - f191057＋0f5c962 計測3-1〜3-3・自己申告4-1／4-1'（体温34.0〜42.0℃）・レポート生成4-2／4-2'・結果4-3／4-5
  - 0fedf13 履歴詳細5-2（新ルート `/history/detail`、個別削除は詳細画面へ移動）・推移グラフ5-4（リスト／グラフ切替。1週間＝今日まで7日、1か月＝今日まで30日。体調は棒グラフ、推定心拍は実データのみ折れ線。チャートパッケージ追加なし）
  - 検証：dart format OK、flutter analyze 指摘なし、flutter test 322件成功。実機・シミュレータでの見た目は未確認（Macの空き容量不足。Xcode26.4では既存のiOS27 API参照でビルド失敗する既知問題はSTATE記載済み）。
- mainへの統合はUI全体の確認後に行う。

## 維持するもの

- 現在のSwiftUI Liquid Glassタブバーとスライド動作・タブ切替。
- 保存済みの実測値とnull、出典表示、削除確認、AI生成前保存。
- 比較は今日を除く直近7日・有効記録3件以上。デザイン例の7日分蓄積条件へ自動変更しない。
- 中断／失敗記録は保存しない。品質不足の架空履歴を追加しない。
- Cの計測・AI内部、研究モードの有効化条件にはUI反映だけで変更を加えない。

## 段階反映の注意

- サンプルの測定値・日付・レポート文を実データとして入れない。
- 今週の花は日曜始まり、その日までの良好な記録がある日を1輪とする。同日複数回でも1輪。未来日は数えない。
- 取得できなかったキャラクター画像は仮の花アイコンで表示。元画像の受領後に差し替える。
- グラフ切替は推移グラフ5-4で実装済み。動かない切替ボタンは置かない。
- 自動計測開始・体温範囲34〜42℃・研究モード設定・クラウドを示唆するエラー等、現行動作と異なる箇所は見た目だけで採用しない。

## 現行仕様との相違点（2026-10-18 全画面反映）

ユーザー決定：計測開始はボタンのまま（見た目のみ合わせる）／比較条件は「今日を除く直近7日・有効3件以上」を維持（デザインの「7日分」表記は「3日分／3件」に書き換え）／追加画面は初回設定・体温範囲チェック・推移グラフ・このアプリについて。

採用しなかった・変えた点：

- 1-8 TipKit：永続化せず、初回設定完了直後のみ表示。
- 研究・実験モード行（6-5）：設定が存在しないため未実装。
- 「設定アプリを開く」ボタン：依存追加なしでは実装手段がないため、手順表示のみ。
- プライバシーポリシー行：本文がないため省略。免責事項は「このアプリについて」内に記載。
- 6-2／6-5'：スクリーンショット未取得のため未反映。
- 4-4 品質不足の結果画面：現行フローで到達しないため未実装。
- 結果画面：表示後の入力編集ボタンを廃止。
- 品質ラベル poor は「不足」に統一。
- 「通信できませんでした」等クラウドを示唆する文言は不採用。
- キャラクター画像：仮アイコン（`AsakaoMascot`）。フォントはシステムフォント。
