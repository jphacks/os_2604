## 研究モード（決定済み）

2026-10-18、ユーザーが通常／研究の切替を採用。撮影画面の「研究モード」は既定オフ。オンの場合だけ `day1Experimental()` を使う。画面を開くたび通常に戻り、開始後の再試行・保存中は変更不可。設定としては保持せず、各結果のモードを保存する。

通常は実験処理を停止し心拍・顔色をnullにする。研究は推定値が得られない場合も研究モードとして保存する。結果・履歴詳細・新しいレポートにモードを表示。schema v5で既存記録は「モード未記録」として保持し、過去のモードを値から推定しない。A観点レビューは実施済み。研究表示は確認できたが、撮影入口のshould 2があるため最終UI承認は保留。[レビュー票](a-ui-review.md)参照。

## 精度・制約の説明

発表で使う説明案：

> 心拍は、顔の色の変化から求める研究用の試験的推定値です。照明、顔の動き、機種や肌の写り方に影響されます。品質条件を満たさない場合は数値を出しません。実機での比較は1回で、精度を保証する検証は完了していません。診断や健康状態の判定には使用しません。

- **照明**：暗所・白飛び・逆光・照明変動で結果が変わり得る。同じ場所・明るさで正面を向く。露出固定はベストエフォートで適用成功を保証しない。
- **動き**：顔の移動・角度・表情変化はRGB信号やROIに影響する。途中の顔外れ・離脱は無効／中断として保存しない。
- **機種・肌の写り方**：センサー、露出、色補正、肌色等の差を吸収できる保証はない。iPhone 17 / iOS 27.0.1以外や全利用者への精度を保証しない。
- **品質とnull**：P0撮影品質が合格でも、P2信号品質不足なら心拍は `null`／「未測定」。撮影品質の合格は心拍の正確さを示さない。品質不十分・中断の記録は保存値があっても心拍数を非表示にする。
- **顔色**：顔内側ROIの `R / (R + G + B)` の中央値という外観特徴量。血色の良否・病気・体温の判定値ではない。同条件での相対変化の研究用。
- **AI**：端末内モデルが固定短文キーを選択。数値・出典・過去比較はDartで文章化。自由な診断や精度保証をAIに依頼しない。利用不可・生成失敗時は定型文へ切替。
- **比較の限界**：心拍ブランチのSTATEにApple Watch同時比較1回の記録がある。反復・人数・条件別検証や統計的精度評価ではない。個人の実数値・顔画像を資料やGitへ転記しない。

## P2の品質条件（`315cf61` のコード照合）

POS既定／CHROM選択可。30fpsを指定してRGB取得を顔検出から分離し、顔検出は180ms間隔・4倍縮小、ROIは3%デッドバンドで安定化。指定fpsと実効fpsは同じとは限らない。

| 項目 | 現在の実験設定 |
| --- | --- |
| 心拍用サンプル | 120以上、観測区間14秒以上、間隔500ms以下 |
| 照明 | 輝度50〜245、輝度変動係数0.15以下 |
| 信号飽和 | RGB各成分が5未満／250超なら推定しない |
| 周波数探索範囲 | 48〜180 bpm相当（正常範囲ではなく探索上の制限） |
| ピーク条件 | power ratio 0.24以上、prominence ratio 1.4以上 |
| 顔色 | 30サンプル以上・照明安定時に算出 |

実装上の採否条件であり医学的妥当性や精度の根拠ではない。合成テストの成功も実環境の精度保証にならない。
