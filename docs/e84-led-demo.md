# iPhone・E84 LED通知の実装と実機試験

## 実装範囲

- iPhoneのみ。`flutter_reactive_ble 5.6.0` を固定し、Bluetooth利用説明を追加。位置情報・背景通信・クラウド送信は追加しない。
- 設定で10秒間検索し、広告名が `Find Me Target` の機器、またはIASを広告する機器を候補に表示。公式Find MeはサービスUUIDを広告しないため、OS側のIAS検索フィルターは使わない。名前・識別子を表示してユーザーが選択し、接続後にサービス・特性・Write Without Responseを検証する。
- 接続時・計測開始準備時に消灯。有効計測のDB insert成功後に最大1回の点灯。AI・送信完了を結果表示が待たない。
- 点灯書き込み完了の約3秒後に消灯指示。送信上限2秒。操作を直列化し、試行・接続・操作の世代で古い処理を無効化する。タイムアウト時は接続を破棄し自動再送しない。投入済みBLE命令の撤回・実点灯確認はできない。
- 通常の結果画面遷移ではタイマーを保持。取消・背景化・切断では破棄し、可能なら同じ接続へ消灯を試す。消灯を保証する表示はしない。
- 初回カメラ許可ダイアログのinactiveは既存の計測契約に合わせて保持する。計測中や保存中の離脱は遅延完了をLED通知しない。
- 連動は接続ごとに既定オフ。接続ごとにLEDテストと目視確認後のスイッチ操作が必要。接続先・連動状態・送信キューは永続化しない。
- DB形式・計測の時計・品質閾値・健康結果型は変更しない。LED操作は健康履歴を作らない。

## セットアップとデモ

2026-10-17のコード検証は整形差分なし、静的解析の指摘なし、Flutter全284テスト成功、`tool/flutter_with_xcode.sh build ios --no-codesign` 成功。BLEプラグインが使用するSwiftProtobuf 1.39.0の解決結果をPackage.resolvedに保持。ML KitのSPM非対応警告は既存のCocoaPodsフォールバックでビルドされた。

同日、既存の有効な署名・端末登録を使い、今回のブランチのRelease版を署名付きでビルド。署名検証後、iPhone 17／iOS 27.0.1の既存 `com.example.os2604` へ更新インストールし、起動とプロセス継続を確認した。アンインストール・記録削除は行っていない。その後の2026-10-18に健康チェックアプリで実機試験を実施（結果は下表）。キット単体では2026-10-18にAIROCから点灯・消灯できたとのユーザー報告を取得。署名情報はビルド引数で渡し、共有プロジェクトにチームを固定していない。

1. [キット手順](../firmware/e84/README.md) で公式サンプルを書き込み、AIROCで単体点灯・消灯を確認する。2026-10-18にAIROCから点灯・消灯できたとユーザーが報告。
2. `flutter pub get` 後、iOSを再ビルドする。署名・インストールは既存の実機手順に従う。既存アプリ・DBを削除しない。
3. AIROCを切断。アプリの「設定」→「キットを検索」→対象機器を選択。見つからなければAIROCでDisconnectして終了し、キットをRESETしてすぐ検索する。給電・Bluetooth・権限も確認する。
4. 「LEDをテスト（約3秒）」で対象実物の点灯・消灯を確認する。健康記録は作られない。「実物を確認済み：計測の保存完了と連動」をオンにする。
5. ホームへ戻って計測。顔位置確認→15秒→保存→点灯指示→結果画面→消灯指示を確認する。LEDは保存完了を意味し、健康上の正常・異常を示さない。
6. 結果の追記・レポート生成・履歴の再表示で再点灯しないことを確認する。アプリが背景化／切断すると連動がオフに戻る。再接続後は手順4を繰り返す。
7. 初回モデル等の準備後、機内モードでBluetoothだけオンにし、Wi-Fi・モバイル通信オフで最低2回通す。

2026-10-18の検索不具合修正：AIROCでは単体操作できたが健康チェックアプリではRESET直後も表示されないとユーザー報告。書き込んだ公式Find Meの `GeneratedSource/cycfg_gap.c` はFlagsとComplete Local Nameのみを広告し、IAS UUIDを含めない。IASのOSスキャンフィルターを外し、名前またはIAS広告で候補を選別するよう修正。接続後はGATTのIAS／Alert Level／Write Without Responseを引き続き検証し、16ビットUUIDも128ビットへ正規化して比較する。回帰3件を含む全287テスト、静的解析、78ファイルの整形確認が成功。修正版の署名付きReleaseビルド・署名検証・既存iPhoneへの更新インストール・起動が成功。修正版でFind Me Targetが表示され、選択後に接続済みになったとユーザーが確認。アプリのLEDテストで点灯して約3秒後に消灯し、連動オン後の15秒計測では計測後だけ1回点灯・消灯したとユーザーが確認（L01）。途中キャンセル後の遅れた点灯なし、履歴から再表示で再点灯なし、オフライン2回の保存・点灯・消灯もユーザーが確認。残りの実機試験は上表のとおり。
